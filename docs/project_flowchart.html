MLOps Reference Architecture

Energy-Market Demand Forecasting — End-to-End Pipeline

Data flows top to bottom through eight lifecycle stages. Each stage names the framework that powers it and the folder it lives in. The platform layers on the right operate across every stage.

Cross-cutting platform layers

These run across all eight stages — not a single step in the flow.

Orchestration

Chains stages 01→06 and re-runs only what's stale.

DVC 3.67 · dvc repro → dvc.yaml / dvc.lock

Tracking & Registry

Experiment tracking + model registry; UI on :5000.

MLflow 2.19 → mlruns/ · mlartifacts/ · mlflow.db

Lineage

Every stage emits lineage events for an end-to-end graph.

Marquez + OpenLineage 1.49 → src/lineage.py

Packaging

Containerises app + training; one-command local stack.

Docker + Compose → Dockerfile · docker-compose.yml

CI/CD

test → build image → deploy on every push to main.

GitHub Actions → .github/workflows/ml-ci.yml

Deployment

GitOps rollout of app, Postgres, Prometheus, Grafana.

Kubernetes (minikube) + ArgoCD → k8s/
